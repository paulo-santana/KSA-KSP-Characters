First release: the Kerbal from Kerbal Space Program as a crew character in Kitten Space Agency, with its body, helmet, visor, jetpack and KSP's own animations. The jetpack is from KSA

## Install

1. Download **KSP-Characters-v0.1.0.zip** below. The "Source code" archives will unpack under the wrong folder name.
2. Unzip it into `Documents/My Games/Kitten Space Agency/mods/`, so you get `mods/KSP-Characters/`.
3. Start the game. It detects the mod by itself.

Kerbals join the pool the game draws crew from, so new crew members are a random mix of kittens and Kerbals. Existing saves keep the characters they already have. So far to figure out which one are kerbals, i'd create a ship with 10 Gemini capsules so I can fill them with the entire initial character roster

## Known limitations

- The face has no expressions.
- The seated pose doesn't move yet.
- Kerbals get random kitten names.
- I removed the "look at the camera" eye animation as they are very cursed for kerbals.
- The walk plays faster than in KSP, because KSA moves crew faster. It has been slowed down as far as it can be without a code mod.
