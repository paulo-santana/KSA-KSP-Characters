# KSP Characters for Kitten Space Agency

Adds the Kerbal from Kerbal Space Program as a playable crew character in KSA: body, helmet, visor, jetpack (the game's own MMU), and KSP's own animations. It comes in two suits, each its own character: KSP's white EVA suit (`Kerbal`) and an orange one (`KerbalOrange`), a recolor of the same suit.

## Install

1. Copy this whole folder (`KSP-Characters`) into `Documents/My Games/Kitten Space Agency/mods/`.
2. Start the game. It detects the new mod by itself.

That is all. Kerbals join the pool the game draws crew from, next to the kittens, so new crew members are a random mix. Saves that already exist keep the characters they have.

If the Kerbal does not show up, open `Documents/My Games/Kitten Space Agency/manifest.toml` and make sure the `KSP-Characters` entry has `enabled = true`.

## Contents

* `KerbalAssets.xml`: the character definition (Id `Kerbal`).
* `Characters/Kerbal/`: body, helmet, visor and the animations, one file per KSP clip (slots that play the same clip share it).
* `Characters/KittenMMU/`, `Textures/Characters/`: the game's own jetpack, copied so the folder works on its own.
* `Textures/Kerbal/`: the Kerbal's textures (`Body_A.png` is the white suit, `Body_Orange.png` the orange one).

## Known limitations

The jetpack keeps one floating pose whatever the thrust (as in KSP), the face has no expressions or blinking yet, the seated pose is still, and Kerbals get kitten names. The eyes keep KSP's own animation instead of following the camera.
